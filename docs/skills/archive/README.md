# Archived skills

Skills moved here on 2026-10-08 in the boundary session ([`docs/prompts/crittercab-v2-boundary.md`](../../prompts/crittercab-v2-boundary.md)) because no code in this repository exercises them. The rule of admission ([`docs/vision/README.md`](../../vision/README.md) § Technology stack) admits a skill only when code here exercises it under CI. They were moved, not deleted: retrospectives and prompts cite them by name and path, and their content is a starting point when the technology they describe enters the build.

A skill leaves this folder when the PR that introduces its first exercising code re-sources it against the pinned package version and moves it back, in the same PR.
